# ストーリー資料の反映（0.15.0）

提供された `quiz_toukiden_story.txt` は、原作の台本ではなく、原作情報を基にした再構成資料である。資料を作品内に複製せず、大災いから八年、故郷を離れた人々、神木に関わる存在、小さな狐と旅を続けること、里の再興が長い目標であることを出発点とした。会話・場面の順序・固有名・外見は独自に創作した。灯守は本作の創作上の存在であり、ミタマとして編成するキャラクターではない。

資料の筋立てを参考にした独立作品であり、原作の台詞や個別の場面、結末を復元したものではない。現時点では序章と、仮任務の達成に応じて開く短い創作場面3本を収録する。仮任務やこれらの場面は原作の実際の章として扱わない。既存の任務達成記録から解放状態を判断し、物語専用のセーブ移行は行わない。いつでも読み返せる。

原作の詳細な場面の順序、会話、終盤の展開は未確認。その後、分割されたAPKを結合して静的調査できたが、物語の台詞や場面の順序はまだ確認できていない。詳しくは `docs/APK_RESEARCH_0.16.md` を参照。APKから抽出した素材、音楽、文章、プログラムは使用していない。
