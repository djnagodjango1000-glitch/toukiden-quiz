# 提供されたAPKの調査メモ（0.16.0）

## 対象と方法

ユーザーが提供した分割ファイルを結合し、圧縮ファイルからAPKを取り出した。APK自体のZIP整合性は検査済み。ファイル名からバージョン1.1.2とされるが、公式配布物と同一であること・署名の真正性は検証していない。APKは起動せず、格納ファイル一覧、Unityアセットの種類、管理コードの型・メソッド名だけを静的に確認した。ファイルのSHA-256は `8f80ea44aaf0067ced715b1f90e60bd49e375b290b443122390ede911a38bfb1`。

## 確認できたこと

- Unityのデータと管理コードが存在する。Unityの個別アセット1068ファイルを読み、画像・音声・アニメーションなどの種類を確認できた。原作の素材・コードを本アプリに組み込んでいない。
- 管理コードには任務の補助目標の判定や結果表示を示す名前があり、正答率、平均時間、連続正解数、回答数、全部位破壊、属性・編成などの条件を示唆する名前がある。これはそれらの処理構造がAPKに存在する証拠であり、実際の任務でどの条件が使われたか、計算方法、閾値、報酬や画面の動きを証明するものではない。
- 調べた個別Unityアセット1068件ではテキスト資産は2件のみで、名前は設定およびローカライズを示していた。これだけで、物語がAPK内の別形式に存在しない、あるいは当時のサーバーから取得されていたと断定することはできない。ストーリーの台詞、順序、終盤は未確認。

## 今回の独自実装

上記の補助目標という仕組みを参考に、試作任務へ挑戦目標を設定。正答率・平均回答時間・最大連続正解を使い、任務前に条件、勝利後に結果と追加ハクを表示する。条件値、対象任務、報酬はすべて本作独自の暫定値であり、`data/challenges.json` で変更できる。平均時間は通常四択の全回答を対象とし、時間切れは制限時間で計上する。ムスヒノ刻の○×は含めない。同一戦闘の結果再表示では報酬を重複支給しない。

属性や部位破壊を条件とする目標、原作の個別任務構成、正確な報酬・演出は未実装・未確認。調査結果を原作の完全再現と見なさない。
