# ミタマ辞典を踏まえた仕様変更書

調査日：2026-11-17／比較対象：鬼問戦記 0.12.0／状態：**実装前の提案**

0.13.0追記：解答補助の暫定実装、事典の詳細・所持／属性フィルター、一部のWiki掲載例の参考表示に着手。人物・★別の版、版別進化や本来の行動順は未実装。以下は0.12.0時点の比較と引き続き必要な変更。

指定された[『クイズバトル討鬼伝』攻略Wikiのミタマ辞典](https://seesaawiki.jp/toukiden-quizbattle/d/%a5%df%a5%bf%a5%de%bc%ad%c5%b5#7)と、リンク先の個別ページ・技一覧を確認し、現在のアプリと比較した。今回、ゲーム本体やセーブデータは変更していない。

## 前提と資料の確かさ

- 指定サイトは**非公式の攻略Wiki**。実際に記載を確認したが、原作の公式資料や実機の裏付けまでは取れていない。従来のA/B/C分類では、単独の後年Wikiでの記述は**C：要追加検証**とし、原作の確定値として扱わない。Wikiの空欄は「不明」であり、ゼロや該当なしとは限らない。
- ユーザーの指定により、仲間として登場するミタマは**歴史上の人物に限る**。Wikiにある神話・おとぎ話・創作人物や他作品コラボは仲間に追加しない。人物の実在や同定に議論がある場合は別途検討する。
- 原作らしさと人物の史実にちなんだ個性を両立させる。Wikiの技の仕組みを優先して検討し、名称・演出は歴史上の活動を参考にした独自制作も可能とする。記録が矛盾・不足する部分は仮仕様として区別し、既存の創作技を確認済みの原作技と表示しない。
- 原作・Wikiの画像、文章や問題文を大量に複製しない。画面や機能の参考にし、製品には独自の絵・文章・音を使用する。現実のお金による課金・広告・ログインは設けない。

## 現在のアプリとの具体例

以下は比較のための少数例。数値や名称はWiki記載であり、公式に確定した値ではない。

### 新島八重

- [Wikiの★5ページ](https://seesaawiki.jp/toukiden-quizbattle/d/%a1%fa5%20%bf%b7%c5%e7%c8%ac%bd%c5)では、突属性・コスト23・神速・時代「乱」。体力はLv.1で2212、Lv.50で3734、攻撃はLv.1で1767、Lv.50で3902と記載。
- 同ページには★6への進化先がある。[★6ページ](https://seesaawiki.jp/toukiden-quizbattle/d/%a1%fa6%20%cb%eb%cb%f6%a4%ce%c1%c0%b7%e2%bc%ea%20%bf%b7%c5%e7%c8%ac%bd%c5)にはさらに★7への進化先が記載される。進化素材欄の空白は未確認として扱う。
- ★5のハヤフリはWikiの技一覧で「突属性のミタマの攻撃力を強化」、タマフリは「突属性のミタマを2回強化、消費2」と説明される。一方、本アプリの新島八重は斬属性で、独自の追加攻撃と「攻撃＋防御」の技。**対象・属性・効果・消費が異なる。**
- 対応案：まず★5・★6・★7の差を別バージョンとして設計し、突属性限定の強化を扱える戦闘処理を追加する。確認できない進化条件は仮条件と表示する。

### 清少納言・聖徳太子

- [★5清少納言](https://seesaawiki.jp/toukiden-quizbattle/d/%a1%fa5%20%c0%b6%be%af%c7%bc%b8%c0)は突属性。Wikiの技一覧には斬属性の被ダメージを指定回数軽減するタマフリがある。現在のアプリは砕属性で回復技。**属性を指定した防御と、被弾回数による消費**が不足している。
- [★3聖徳太子](https://seesaawiki.jp/toukiden-quizbattle/d/%a1%fa3%20%c0%bb%c6%c1%c2%c0%bb%d2)は突属性で、Wikiの技一覧には選択肢を2個削るタマフリが載る。現在は斬属性で攻撃支援技。**クイズを助ける技**が不足している。発動可能な画面や効果の持続などは追加調査が必要。

## 変更仕様・優先順位

### 優先1：ミタマの版・進化・育成

1. **人物と版を分ける。** 人物ID、版ID、表示名、★、属性、時代コード、コスト、速度区分、初期・最大能力、レベル上限、技、進化先、根拠と確度をデータ化する。Wikiの別版を一律に進化系と決めず、個別ページのリンクで確認する。
2. **進化先を個別に定義する。** 素材・費用・レベル条件・進化先・能力の変化を版ごとに持つ。材料や条件が未記載なら「未確認」とし、遊べる暫定条件を別設定にする。現在の全員共通Lv.5、素材2、2段階の処理を見直す。
3. **能力・成長を段階ごとに設定する。** 初期・最大値とレベル上限を個別に表示。中間値の計算式はWikiの2点だけでは決められないため、仮の成長曲線を設定可能にし、確定扱いしない。既存のレベルや成長結果が突然消えないよう移行を設計する。
4. **素早さ・時代を追加する。** Wiki記載の速度区分と時代コードを表示・絞り込みに使う。現在の数値速度からの換算、同速度時の順序、「古」「雅」等の詳細な意味、特殊コードの扱いは追加調査後に決める。特に一覧の「進」「強」「習」は一般の時代名と決めつけない。
5. **コスト上限を再設計する。** 現在の上限10では、Wiki記載の★5新島八重コスト23を1体も編成できない。原作の上限・上昇条件は未確認なので、所持済み編成が必ず成立する暫定上限・成長方法を別設定し、検証してから採用する。

### 優先2：ハヤフリ・タマフリの仕組み

1. **対象・回数・消費を技ごとに定義。** 自身／全員／指定属性の味方、敵1体／複数、対象属性、倍率・固定値、適用回数、消費pt、重ねがけをデータ化。たとえば突属性限定の2回強化を、属性の異なる味方に誤適用しない。
2. **属性別・回数別の防御を追加。** 斬属性への軽減などを実装し、被弾ごとに残り回数を減らす。現在の「次の敵行動全体を一度軽減」とは別に扱い、複数敵・複数回攻撃時の消費単位を検証する。
3. **解答を助ける技を追加。** 選択肢を2個減らす技では、正答を必ず残し、誤答から選ぶ。巻物更新も別の技として追加する。発動タイミング、更新対象、重複や時間切れの扱いは未確認のため暫定ルールとして明記する。
4. **反射・行動順操作を追加。** 敵の攻撃を指定回数反射する効果や、敵の行動を遅らせる効果を実装する。現在は回答後に生存敵が一斉反撃するため、行動順操作を忠実に扱うには**敵と味方を含む行動列**の再設計が先に必要。正確な順序・遅延単位は未確認。
5. **パッシブ等のスキル欄を調査する。** 個別ページに「スキル」欄はあるが、確認したページは空欄もあり、発動条件や全員の所持を断定できない。記載を収集し、確かめられたものからデータ構造を設計する。

### 優先3：事典・獲得・遊びやすさ

1. **事典を版ごとに閲覧可能にする。** 未取得の表示、★・属性・時代・速度・進化先・能力・技の確認を設計する。未取得でどこまで見せるかは原作未確認。人物の史実紹介も引き続き載せる。
2. **絞り込み・並べ替えを追加。** 人物名、★、属性、時代、速度、所持状況、進化可能、技の種類で探せるようにする。原作のUI詳細は追加調査しつつ、縦画面で操作できる設計にする。
3. **獲得と素材のオフライン化。** 現在の召喚は未所持50体から等確率・重複なし。版が増えた場合の入手経路、重複の扱い、進化素材、枠、ゲーム内通貨の収支を設計する。Wiki上の名無しの素材等を歴史人物の仲間として追加せず、独自の素材アイテムへ置き換える。課金専用・限定配信の要素もゲーム内で無料入手できるようにする。確率は確認できなければ暫定として表示する。
4. **操作前に違いを見せる。** 強化・進化・編成時に属性、技、成長、素材、消費コストを前後比較し、確定前に確認できるようにする。すでにある確認画面を版別データに対応させる。

## データ設計と既存セーブ

現在は人物IDごとに所持、編成、レベル、進化段階を保存し、同じIDを複数所持できない。人物と版、必要なら所持個体を分ける際は、以下を実装条件とする。

- 既存50人のIDを対応表で新しい版IDへ明示的に対応させる。**所持・編成・育成・進化・通貨・報酬・進行状況を保持**する。既存の創作肖像も引き続き表示できるようにする。
- セーブ形式を変更する場合はバージョンと移行処理を用意し、読み込み時に旧データを検証する。移行の再実行や途中終了で二重変換・データ消失を起こさない。変更前のバックアップを残し、不明な新形式・破損時は自動上書き・初期化しない。
- 元の数値と新しい数値の尺度が大きく異なるため、原作Wikiの数値だけを既存戦闘に入れない。成長・敵HP・報酬・上限をセットで調整し、既存プレイヤーが任務を継続できることを検証する。
- 歴史上の人物限定、無料・オフラインの方針をデータの検証条件に含める。個別の歴史的事実とゲーム上の効果は別フィールドで保持する。

## 実装後の受け入れテスト

1. 旧セーブを読み込み、所持・編成・レベル・進化・通貨・任務進行が保たれ、移行を再実行しても変わらない。破損時や途中終了時に復元できる。
2. 一人の人物に複数の★・版を登録でき、別版の技、属性、コスト、進化先が混ざらない。未確認値は不明として表示される。
3. 指定属性強化は該当する味方だけに、指定回数だけ適用される。防御・反射の対象と残回数が正しく減り、過剰適用されない。
4. 選択肢削減は正答を残す。巻物更新、時間切れ、回答中の二重操作をテストする。敵の遅延は行動列と表示が一致する。
5. 編成上限・コスト・進化素材・所持枠・報酬の重複付与を検証し、旧セーブの編成で出陣できる。
6. 固定乱数・模擬時計を用いた戦闘テスト、オフラインでの取得・育成、セーブ／バックアップの復元、Androidの画面とタッチを確認する。実機で未検証の項目は区別して報告する。

## 未確認事項

- Wikiの各数値・技能の正確さ、掲載時期と配信終了時点の差、一覧の空欄、全バージョン・全進化経路。
- 行動順・神速等の正確な速度と同速順、回答補助技の発動タイミング、軽減・反射の厳密な回数消費、技の重ねがけ。
- 戦闘のダメージ式、コスト上限の成長、ガチャの当時の排出率、事典の詳細画面や未所持の表示。
- 元の資料に載る人物のうち、歴史上の実在人物に限定した選定と追加候補の検証。
